# Pet Adoption Management System

A web-based pet adoption platform developed for the CSE370 Database Management project.

## Features
- Pet profile management
- Shelter management
- Adoption applications
- Adoption records
- Medical records
- Donation tracking
- Activity logs
- User roles: Adopter, Volunteer, Admin
